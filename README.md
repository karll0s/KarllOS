# KarllOS

Sistema operacional pessoal baseado no [Aurora](https://getaurora.dev/),
construído e personalizado com [BlueBuild](https://blue-build.org/).

## Objetivo

Criar um sistema reproduzível, versionado e fácil de manter, aproveitando
a infraestrutura do Universal Blue em vez de recriar soluções que já existem.

## Princípios

- Reutilizar o que Aurora e Universal Blue já oferecem.
- Manter a imagem do sistema mínima.
- Usar Flatpak para aplicações gráficas.
- Usar Homebrew para ferramentas de linha de comando.
- Usar containers/Distrobox para ambientes de desenvolvimento.
- Versionar configurações e receitas no Git.
- Separar configuração comum de configurações específicas de hardware.
- Evitar armazenar dados pessoais ou segredos no repositório.
